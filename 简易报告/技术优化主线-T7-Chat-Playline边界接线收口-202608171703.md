## 做了什么

- 新增 `server/boundaries/chat-playline.js`，只暴露 `chat(command)` / `playline(command)`；Direct Chat 负责正式账号 admission、双向 Block/好友策略、NFC 纯文本边界、幂等、分页、未读、单调已读、四级频控和有界状态。
- 修正 Test Admin 目标的稳定错误分类：`resolveTarget()` 保留 `test_admin_isolated`，不再被 caller 降级为 `invalid_target`；history/read 先执行查询频控以保持旧 inline/Supabase 顺序；新增管理员脏历史不进入 list/unread 的安全回归。
- 提供 detached memory 与 JSON legacy/canonical Adapter；发送和已读 mutation 在单进程 seam 内串行化，避免并发 `nextSeq` 冲突或游标回退。
- `server/index.js` 的本地 JSON 私聊 handlers 接入新边界；WebSocket wire、session token 复核、广播和 Cluster fan-out 继续由 caller 负责。真实 Supabase 配置下 Direct Chat 保留既有 `send_direct_message_v1` / `apply_direct_message_read_v1` 事务路径。
- 既有 `server/playline.js` 作为内容 owner 注入新边界；list/publish/remove/report 四动作统一委托，边界再次移除私有字段，不改变 feature flag、内容类型、游标、举报或 Supabase RPC。
- T7 Node fresh-child 隔离也在本阶段收口：独立 PID/env/module cache/real wall clock、超时/输出上界和 dispose 均有专项回归；不虚拟化 server 全局 `Date.now()`/Timer。
- 更新 TECH-039/040/052、SOC-012、T7 active 合同、PROJECT_STATUS、总/社交/技术进度报告、package/Quality Gate 与三份日志；没有新增 Requirement ID。
