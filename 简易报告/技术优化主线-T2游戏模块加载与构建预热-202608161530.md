# 技术优化主线 T2 游戏模块加载、确定性构建与安全预热简报（202608161530）

## 一句话结论

T2 已完成本地实现与当前构建可见复核：六款既有 Ghost3D Renderer island 具备按需加载、确定性构建检查和受控 Service Worker 预热；完整质量门禁与 `npm test` 均通过，仍保持 `LOCAL_ONLY / NOT_RELEASED`。

## 做了什么

- 新增 `public/src/core/14-game-module-loader.js`：固定六个 gameId/renderer 资源、完整 SHA-256 manifest、单飞加载、导出函数验证、失败回到现有 inline DOM/Canvas fallback。
- 六款 Renderer 调用方统一通过 Loader；不创建 Adapter、不接管 Ghost3D Foundation 生命周期，不触碰 Rule、Authority、Protocol、Reward、Replay、Social 或 Persistence。
- `public/sw.js` 增加 `ghost-game-renderer-v14-20260816` 独立缓存；只接受显式 `GAME_MODULE_WARMUP_V1`，固定 allowlist、同源/MIME/no-store/basic/哈希校验与并发去重。登录、首页、安装路径不预载 Three/GSAP。
- `scripts/build.js --check/--write` 增加确定性字节比较、同目录临时文件、`fsync`、原子 rename、失败保旧产物与 characters/UTF-8 bytes/SHA-256 输出。
- 新增 ADR 与专项 QA：`requirements/ADR/002-game-module-loader-cache-build.md`、`qa/game-module-loader.js`、`qa/build-check-write.js`、`qa/sw-game-module-preheat.js`。
- 三份中文日志已同步记录新增、修改、删除事项；七份分类/总进度报告已依据台账重新生成。

## 用户现在能看到什么

- 当前本地构建在独立端口 `http://localhost:8091` 真实启动并登录测试账号后复核。
- 五档视口（1440×900、1024×768、768×1024、390×844、844×390）× Home/Games/Playline/Profile 共 20/20 路由可见；零横向溢出、零裸 i18n key、页面滚动回到顶部。
- 六款本地 AI Game Stage 均可进入并返回：五子棋、飞行棋、迷你大富翁、坦克大战、俄罗斯方块、象棋；Stage/Header/Seat Rail/Arena/Command/Back 均存在，零 console warn/error。
- English、Українська、中文可即时切换；白天/黑夜主题可切换并恢复；reduced-motion 停止环境动画；forced-colors 保留品牌可见性。

## 风险与下一步

- Renderer 仍是 default-off/可回退的表现层；真实 WebGL、低端 FPS、物理设备和网络仍需外部证据。
- Service Worker 只预热固定已知 Renderer 资源；真正六款逻辑游戏 code splitting 必须另立 ADR。
- 下一主线直接进入 T3：先做 `FeedbackBus` 生命周期与 `GameplayInputGate` 的可关闭、reduced-motion/后台/静音安全边界，保持旧同步输入回退。
