# TECH-027 当前构建 PROVE P2 本地收口

## 一句话结论

当前 `public/index.html` 已完成单一 Codex in-app Chromium 的五档四区、共享弹层、六款 Game Stage、三语言、双主题、visible reduced-motion 与 forced-colors 重采集；证据与构建 SHA/bytes 绑定，外部设备 Gate 仍严格阻塞。

## 做了什么

- 修复 forced-colors 认证页主题按钮 42px、登录/注册 Tab 37px、输入 40px 的触控下限，统一达到 44px。
- 修复后置组件 CSS 把 <=1024px 顶栏/导航 44px 合同覆盖回 38/42px 的 cascade 缺陷。
- 建立当前构建证据防陈旧合同，解析 full-source artifact 并校验 SHA、bytes、浏览器数量、5 个 viewport、4 条路由、6 款 Game Stage 与 notGranted。
- 把旧 P1 全矩阵和六款旧 Ghost3D 可见证据改为 historical as-of，报告生成器按当前哈希动态使用“当前/历史”措辞。
- 将防陈旧合同接入 Quality Gates 和 `npm test` posttest。

## 用户现在能看到什么

- 1440×900、1024×768、768×1024、390×844、844×390 下的 Home/Games/Playline/Profile 均无横向溢出、裸 key 或错误滚动。
- Shop、玩家私信、成就、房间大厅均可打开和关闭，滚动锁与焦点恢复正常。
- 六款游戏均进入沉浸式 Game Stage，显示 Seat、Arena、Command 与框内返回。
- 三语言、昼夜主题、减少动效和高对比模式均保留可见反馈。
