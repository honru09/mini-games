# UI Repair P0.2 本地验收简报

时间：2026-08-10 04:26（Asia/Tokyo）

## 这次完成了什么

- 修复 Header 压住商城、设置、房间弹层的问题；登录页仍保持最高安全层，Toast 仍能显示。
- 创建房间改成完整启动台：先选游戏，再按该游戏人数范围选容量，同时支持公开/私密、是否允许观战、6 位私密码加入。
- 房间码只接受无歧义字符；错误会统一净化并给出三语提示，输入框和主按钮均达到 44px。
- 修复“建房失败后，下一次房间更新可能误换游戏”的隐患：待选游戏现在只认本次成功创建的房间。
- 房间浏览显示等待/进行中、真人/AI、是否可观战、房主资料；Join/Spectate 只信服务端，玩家和观众不会再次看到自己所在的房。
- 普通用户看不到赛事创建、打开或自动弹窗；登出、换号、断线会清理旧管理员状态，再由服务端重新授权。
- Ghost Game 三语主承诺更新为“随时开局，一起成长”及英乌等价表达。

## 主负责人审核纠正

Terra Max 终审发现并要求修复 4 个 P1：管理员态残留、待选游戏未绑定房间、观众自身房未过滤、登录层级被降低；另有 44px 房间码输入缺口。主负责人全部修复后，又在真实浏览器发现 HTML pattern 会抢先阻断统一错误提示，追加 `noValidate` 修复；同时补上用户名密码登录后的 `deviceUid` 同步。
