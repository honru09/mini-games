# 界面排版重构：布局系统 V1 本地收口（2026-08-22 23:40）

## 一句话结论

本批开始把前端排版从“继续往生成的单文件里堆样式”转为可维护的外部布局层：新增 `public/ghost-layout.css`，由模板以独立 stylesheet 加载，覆盖首页、游戏中心、Playline、Profile、Game Stage 的几何、间距、响应式和溢出策略；既有模板 CSS 作为兼容基线保留，未改变规则、协议、经济、社交权限或 2.5D Renderer 边界。

## 做了什么

- 新增 `ghost-layout.css` 外部布局系统，统一最大宽度、页面 gutter、卡片间距、控件最小尺寸和布局断点。
- 首页改为命名网格区域：欢迎、实时状态、六款精选、三步引导、成长目标和社交脉冲不再依赖隐式排列。
- 游戏中心明确区分游戏库、房间大厅、主内容和侧栏；桌面侧栏吸附，窄屏自动单列。
- Playline 和 Profile 保留独立主栏/侧栏几何，长文本使用最小宽度与换行保护，避免按钮、标题和身份节点挤压。
- Game Stage 增加标题截断、命令区滚动栏位和安全焦点边界；不触碰对局输入与权威状态。
- Service Worker 从 v15 升至 v16，并把外部布局样式加入离线 Shell 预缓存。
- 新增 `qa/layout-system-v1.js`，并接入 `npm run test:layout-system` 与完整 `pretest`。

## 用户现在能看到什么

- 桌面端：首页和各路由拥有更稳定的列宽、边距和侧栏关系。
- 平板端：游戏卡、房间面板和侧栏在 900px 附近收敛为可读的单主栏布局。
- 手机端：首页卡片按阅读顺序单列，游戏库卡片单列，Playline 操作按钮满宽且保持 44px 触控目标。
- 主题、reduced-motion、forced-colors 和既有 Ghost Game 2.5D 动效边界仍沿用原语义令牌；本批没有增加持续循环动效。

## 还没做什么

- 生成的 `public/index.html` 仍是部署构建产物；本批先把新增布局从模板中外置，后续再评估把历史兼容 CSS 分批迁移到更细的 tokens/components 文件。
- 浏览器连接在本批复核时发生超时，因此没有把布局提升为当前浏览器可见验证；第二浏览器、真机、真实网络和生产 Supabase 仍是发布证据待决。
- 没有执行线上部署、commit、push 或生产数据写入。
