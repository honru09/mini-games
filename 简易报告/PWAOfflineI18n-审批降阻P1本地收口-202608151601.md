## 做了什么

- Service Worker 升为 v11，安装时缓存三份 locale，只接管同源、GET、无 query 的精确三语 URL。
- API/WS/Auth/Chat/Token 和其他 JSON 继续排除；普通 JSON 即使伪装成 script destination 也不缓存。
- 导航响应只有 `text/html` 可以更新离线首页，避免 JSON 污染 app shell。
- 新增真实 SW VM 专项、ADR-001、P1 缺陷记录、浏览器证据和控制面路由证据。
- 固化 `MACHINE_CONTINUABLE / EXTERNAL_ENVIRONMENT_REQUIRED / HUMAN_ONLY`：大多数技术项不再等待逐项人工确认。
- Terra Max（max）独立只读审查发现并推动修正子路径/三语覆盖、伪 destination JSON 和 JSON navigation 三组遗漏；主负责人逐项审核后才采用。
