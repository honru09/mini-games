# Gomoku Ghost3D P0 本地实现收口（2026-08-12 06:55）

## 结果

`TECH-049` 的第一条游戏纵切已在本地实现，但整体状态继续是 `partial`。五子棋现在拥有 default-off 的真实 Three.js 程序化 Scene：15×15 厚棋盘、实体棋子、灯光、Camera、Raycast、质量阶梯、首镜头和落子动效；规则、联机、AI、Replay、奖励和数据完全没搬进 Renderer。

## 动效与主审修正

- 按官方 `gsap-core`、`gsap-timeline`、`gsap-performance` skill 执行。
- `onReady` 从 mount 移到第一帧真正 render 成功以后，空 Canvas 不再抢指针。
- HIGH 首帧使用可 kill 的 `entrance → settled` Camera timeline；落子使用 `focus → place → settled`。
- LOW 与 reduced-motion 直接进入静态稳定态，不创建 timeline 或常驻 render loop。
- render failure、suspend、context loss、fresh Adapter recovery 和 dispose 都会关闭 3D 指针、清理 GSAP/Three 资源并保留 Wave B。
- 主负责人补上正式 test/pretest/Quality Gate、SW cache 版本、lazy-cache 合同、vendor 换行保护、Three MIT 与 GSAP Standard License notice。
