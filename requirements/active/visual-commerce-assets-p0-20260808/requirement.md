# 白皮书 × 美术 × 商城视觉收敛 P0

## Goal

以当前 `main` 为唯一代码基线，把白皮书与美术资源清单重新落到真实用户入口：完成全站视觉审计，修复线上动态 i18n 裸 key，重构登录/注册与商城的首要信息层级，补齐四款大厅封面，建立轻量素材索引，并清理可安全再生成的本地缓存。

## IN

- 审计 1440px、768px、481px、390px、360px 的大厅、登录、注册、房间入口、档案、商城、排行榜、社交、Replay、赛事和六款游戏 Shell。
- 修复词典加载前动态渲染造成的 `quick_join`、`social_login_required` 等裸 key，并补连续切换回归。
- 登录/注册弹层：单一滚动容器、清晰主次按钮、可读预览、移动端高度与 44px 触控目标。
- 大厅：降低 Hero 空耗，消除重复快速加入，统一六款卡片层级并保持 Fast Fun Loop。
- 商城：分类导航、主预览/试穿舞台、余额与商品状态、购买/装备反馈；客户端目录必须与服务端现有价格合同一致，Starter Background 1–6 只对历史已拥有账号展示，购买价格、owned 与扣款继续由服务端权威。
- 商城弹层必须单例化；注册、登录、取消、商城关闭和重复打开后滚动锁必须可靠回收。
- 游戏顶栏和新增商品名完整覆盖中文、英文、乌克兰语，语言连续切换不得泄漏中文或裸 key。
- 生成并接入六款原创软 3D 竞技卡通大厅封面及 320w 版本；五子棋和俄罗斯方块从旧封面升级，飞行棋、迷你大富翁、坦克大战、象棋补齐；仅标记为可回滚的过渡大厅封面，不冒充新报告最终 Sticker Cartoon 风格或完整游戏美术包。
- 建立轻量本地素材索引：来源、许可、作者、哈希、尺寸、Prompt/模型、状态、在线对象键和低清预览；母图仍留在 `art-source/`，未选择对象存储前不上传外部服务。
- 盘点并清理 `.codex-tmp` 中可重复生成的 DOCX/页面渲染缓存；保留最终交付物、必要脚本与证据。
- 完成三语言、asset manifest、fallback、懒加载、reduced-motion、构建漂移和中文三日志。

## OUT

- 不修改 `server/index.js`、Reward Resolver、服务端商城价格、owned/余额、联机消息、游戏规则核心或 Supabase schema；客户端只对齐服务端既有目录。
- 不宣称四款完整棋盘/棋子/动效/音频包已完成；本批仅完成大厅 P-015 封面。
- 不复制《皇室战争》的角色、表情、构图、图标或受保护资产；只采用原创的高品质竞技卡通标准。
- 不批量抓取、上传或再分发未经授权的第三方素材。
- 未提供 R2/S3/Supabase Storage 凭证前，不创建外部桶、不上传母图。
- 浏览器截图通道不可用时明确记录 `NOT_EXECUTED`，DOM/控制台证据不能冒充截图证据。

## Non-negotiable

- `public/index.html` 只由 `scripts/build.js` 生成。
- 新增文字同步三份 locale；用户原文保持 `data-i18n-raw`。
- 所有新资源具备稳定 asset ID、来源/许可、fallback、加载时机和字节预算。
- 素材目录哈希与许可证哈希必须分字段校验；审计脚本需明确其执行的是仓库显式契约校验，而非通用 JSON Schema 引擎。
- 图片失败、reduced-motion 或低带宽时，现有 CSS/Canvas/DOM Emoji fallback 仍可开局。
- 动效只使用 `MOTION_TOKENS.json`；首屏新增运行时资产预算不超过 500KB。
- 全部实现与验证结束后更新 `LOG-新增.md`、`LOG-修改.md`、`LOG-删除.md`。

## Known Existing Behavior

- 当前线上能完成导航和 DOM 读取，控制台无 warning/error，但动态节点可见 `quick_join` 与 `social_login_required` 裸 key。
- 六款游戏仅五子棋和俄罗斯方块拥有正式大厅封面与 P0 游戏纵切。
- 商城已有服务端权威购买、装备与游戏外观闭环，但前端仍以密集小卡片为主。
- `public/assets` 约 3.98MiB，`art-source` 约 62.56MiB，`.codex-tmp` 约 776.29MiB。

## Expected UX

- 用户进入后优先看到“立即开始、在线的人、六款游戏”，Hero 不挤压首屏主要操作。
- 登录与注册在桌面和手机均无双滚动条，当前步骤、预览和主要行动一眼可辨。
- 商城先看到已试穿效果和当前状态，再看到价格/购买；owned、equipped、insufficient、loading、error 可区分。
- 六款大厅封面保持统一构图、光源、轮廓与卡片比例，同时每款有独立世界色和清晰剪影。
- 切换中文/英文/乌克兰语后，当前已渲染动态节点原地更新，不出现裸 key 或中文泄漏。
