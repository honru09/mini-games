## 产品裁决

- 互动第一、社交第二，个性化是共同基石；头像、头像框、背景、闪名和未来虚拟形象必须进入真实玩家互动，而不是只列在商城。
- 当前正式范围仍是六款游戏与人机/联机两种玩法。长期建设“地区 → 国家 → 特色小游戏”目录，但六款基线完成前不新增游戏。
- 经典规则保持可识别；Ghost Game 特色目标约为体验层的 10%，任何规则变化仍需单独冻结公平、AI、Authority、Replay 和奖励合同。
- 新需求只替代同一语义内的旧体验方向：五子棋末手红框被短促墨线冲击替代；Tournament 普通入口改为默认隐藏。安全、权限、i18n、奖励、防刷、回滚、美术审批和无授权不发布边界不被覆盖。
- 未审批的 Sticker/Honru 资源继续默认关闭；第三方作品只抽象为原创深色轮廓、冲击线、速度感和实体桌游语言，不复制角色、素材、标志或可识别构图。

## 最终新增原子需求

### 美术与品牌

- `ART-033`：五子棋实体斜视棋盘、材质棋子与克制漫画冲击美术；首批四套棋子优先审计玉石、晶体、石质等方向。
- `ART-034`：飞行棋实体棋盘、立体飞机、起飞/移动/碰撞/落地与按真实人数驱动的领奖台美术。
- `ART-035`：Tank 控制完成后的坦克皮肤、地图材质和基地角色化视觉重制。
- `ART-036`：大富翁实体建筑、机会卡、道具、地标和虚拟形象行走美术。

### 界面与交互

- `UI-034`：普通用户默认看不到 Tournament 创建、打开或自动弹窗；服务端、协议、数据、受控入口和测试保留。
- `UI-035`：局内文字聊天图标、未读红点、中央历史、头像框身份行、输入框与十枚 Honru 内联 Emoji UI。

- `UI-037`：大富翁从进入、回合、骰子到拍卖、断线恢复和结算的完整 UI 状态矩阵。

### 游戏与局内体验

- `GAME-041`：五子棋/飞行棋共用的本地 A/B 近端视角映射；每个客户端把本人映射到近侧 A，逻辑坐标唯一不变。
- `GAME-042`：五子棋镜头入场、0.5–1 秒棋子投放、无红框的短促墨线冲击和 reduced-motion 降级。
- `GAME-043`：飞行棋 2/3/4 人场景尺度、实体飞机移动和真实排名领奖台；52 格规则保持不变。
- `GAME-044`：Tank 移动端 360°摇杆主方案、四方向键无障碍降级、独立开火、pointer capture、长按、斜向、取消和离界释放。
- `GAME-045`：大富翁实体棋盘与玩家虚拟形象按服务端位置同步行走，覆盖回合、倒计时、事件和结算表现。

- `GAME-047`：飞行棋随机事件只进入未来候选池，当前不夹带到美术或 52 格规则中。

## 两张参考图的可执行视觉规范

### 五子棋

- 暖米白桌面和木质厚边棋盘，近侧略大、远侧略小但 15×15 点击坐标保持精确。
- 黑白棋子具高光、接触阴影和有限厚度；网格用深棕/墨色细线，避免粗重网页线框。
- 入场镜头只用 transform/opacity，在约 600ms 内聚焦棋盘；reduced-motion 立即到位。
- 已确认落子可在 500–700ms 内从本方近侧投放到交叉点，硬上限 1000ms；动画不能制造第二次点击机会或延迟规则状态。
- 最后一步不再使用红色方框；只使用 100–180ms、6–10 条低密度黑白冲击线/微型闪电，并保留文字/无障碍状态提示。

### 飞行棋

- 仍是 52 格、四停机坪、每方四机；视觉不能为缩短体感删除或合并格子。
- 本人阵营在近侧 A，对手分布于远/侧 B 区；颜色之外保留机翼/轮廓差异。
- 飞机使用原创深色描边、两级色面、柔和投影；起飞、移动、碰撞、落地用短速度线和轨迹，不复制第三方作品。
- 2/3/4 人只调整 Arena 镜头和留白，不改路线；最终以格子可读、无溢出和 44px 操作区为准。
- 领奖台只渲染实际 2/3/4 名玩家：第一最高，第二右侧，其余按冻结构图排列；排序来自可信结算。
