# UI Repair P0.8：商城密度、试穿层级与商品卡排版

状态：`COMPLETED_LOCAL`

时间：2026-08-10（Asia/Tokyo）

## Goal

在不改商品目录、价格、购买协议或资产审批状态的前提下，修正商城“预览不突出、商品卡过密、背景商品层级不清”的体验问题，使桌面、平板和手机都能先看清真实试穿组合，再完成购买或装备操作。

对应台账：`UI-021 / UI-027 / UI-028 / ECO-015`。

## IN

- 桌面商城扩大为 1080px 上限，冻结左侧 268–320px 试穿预览与右侧滚动目录。
- 商品网格使用 144px 可读最小宽度、稳定间距、统一卡片高度、底部价格和全宽操作按钮。
- Premium Background 使用 16:9 poster、更高卡片和“动态/静态”三语层级标签。
- 手机保持单列试穿区、双列商品和至少 44px 操作目标；平板使用自适应多列目录。
- 新增专项静态合同，并纳入完整 `npm test`。

## OUT

- 不修改服务端价格、owned/equipped、购买消息、奖励或 Supabase。
- 不生成、不替换、不默认开启任何未审批美术。
- 不修改游戏规则、Replay、AI、社交协议或生产配置。
- 不提交、不推送、不部署。

## 外部边界

in-app Browser 访问 `http://localhost:8080` 被本机已保存的权限设置阻断；本批没有绕过该限制，也没有把自动化响应式合同冒充真实设备视觉验收。第二浏览器、Android、iPhone、Tablet、真实网络整形和 visible reduced-motion 仍未执行。
