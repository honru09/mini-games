# UI Repair P0.8 冻结合同

1. 商城仍使用现有单例 Modal、滚动锁和试穿数据流，不新建平行商城。
2. 预览只读当前账号与临时候选，不修改 account、Profile、localStorage 或服务端状态。
3. 商品卡内部购买/装备按钮保持独立键盘与指针语义，卡片预览选择不得吞掉按钮操作。
4. 背景动态/静态标签只描述已有资产能力，不代表美术审批或商品价值承诺。
5. 服务端 `SHOP_PRICES`、购买幂等、owned/equipped 和访客边界保持权威且不变。
6. 手机至少保持双列商品、单列试穿和 44px 操作；桌面保持左预览、右目录。
7. 三语新增 key 必须同构；构建产物只能由 `scripts/build.js` 生成。
