# Ghost Game 品牌、认证与应用外壳 P0

## Goal

在不破坏六款游戏、联机、奖励、商城和旧账号数据的前提下，将登录前入口与登录后应用外壳升级为原创 `Ghost Game` 品牌体验；品牌角色统一命名为 `Honru`。

## IN

- 原创黑白幽灵手柄 Logo 与 Honru 首批正式候选；第三方截图只用于抽象视觉语法，不复制角色、构图或资产。
- 登录前独立品牌页：星空运动背景、毛玻璃认证卡、登录/注册/访客、三语言切换、昼夜主题切换。
- 主认证升级为用户名 + 密码：用户名仅 ASCII 字母数字、大小写不敏感唯一；注册时实时检查；密码支持字母/数字/符号并二次确认；注册成功直接建立会话。
- 旧 PIN 账号保留兼容迁移入口；迁移成功后可绑定用户名和密码。既有 token 自动登录继续有效。
- 访客为服务端内存态临时账号，不写本地 JSON 或 Supabase；显式退出立即销毁，断线采用短 TTL 清理。
- 登录后四区应用外壳：Home / Games / Chat / Profile；手机底部导航，桌面/平板顶部或侧边导航；六款游戏只在 Games 区集中展示。
- Home 使用 Honru 轮播 Hero；没有活动时只展示品牌内容，不制造虚假活动。
- Honru 右下角助手：点击抚摸签到、可展开聊天；对话通过服务端 DeepSeek 代理，Key 只在服务端；心情仅由本轮文本推断并明确是推断。
- 双主题：`light` 云海/大气层、`dark` 深空星场；旧主题 ID 兼容映射；个人购买背景保持独立。
- 三语言完整覆盖、新增 QA、日志、简易报告、构建产物与部署验证。

## OUT

- 不删除六款游戏，不修改游戏规则、Reward Resolver、商城价格、owned、赛事或权威协议。
- 不声称 Honru 已完成逐帧最终动画；P0 使用可回滚的原创候选 + CSS 分层动画，后续人工评审再进入精修帧生产。
- 不在未获位置授权时读取定位；P0 不伪造天气。天气只接受用户主动输入的城市并在可信上游可用时返回。
- 不把模型记忆当实时新闻；新闻源未配置/不可用时明确说明暂不可用。
- 不批量抓取或保存第三方素材，不把用户参考截图接入运行时。
- 不把自动化测试冒充真实 Android、iPhone、Tablet、第二浏览器、真实 Supabase 或真实网络整形验收。

## Non-negotiable

- `public/index.html` 只由 `scripts/build.js` 生成。
- 密码使用带随机盐的慢哈希；明文密码、PIN、DeepSeek Key、session token 不写日志、仓库、公开档案或聊天上下文。
- 登录错误按用户要求区分“无对应用户”和“用户名或密码错误”，同时保留频控与固定量级哈希工作，降低用户名枚举的额外时序泄漏。
- 用户名规范化为小写唯一索引，展示保留注册时大小写；Supabase 迁移可重复执行并保持 RLS 关闭浏览器直连。
- 访客奖励、商城、好友、持久训练和跨设备恢复必须禁用或明确标记临时；显式退出清理服务器与浏览器临时状态。
- 全站文案走三份同构 locale；用户原文标记 `data-i18n-raw`。
- 动效遵守 `MOTION_TOKENS.json`、`prefers-reduced-motion`、离屏暂停和输入不阻塞。
- 真实设备、真实 Supabase、真实网络整形与 30 分钟会话未执行前，RC 保持 `BLOCKED`。

## Known Existing Behavior

- 当前是 Playroom 六主题大厅，300ms 后打开 PIN 注册/登录弹窗，登录前仍能看到并操作底层大厅。
- 服务端 `register/login` 以全局唯一 PIN 慢哈希认证；Supabase 只有 `pin_hash` 与最多五个 token。
- 当前已有商城、社交、档案、Replay、赛事和六款游戏，但没有统一 Home/Games/Chat/Profile 信息架构。
- `/api/ai` 已有鉴权、Origin、大小、速率、并发与超时保护，可复用安全边界但必须为 Honru 建立独立提示和响应合同。
- 六主题与个人档案背景存在耦合选择器；迁移双主题时必须保留 `.profile-hero.bg-*` 自身外观。

## Expected UX

- 未认证用户只看到完整品牌登录页，可在进入前切换语言和昼夜主题。
- 登录/注册键盘流程清楚、错误就地可见；注册成功平滑转入 Home，不重复输入凭证。
- Home 展示 Honru 与平台状态，Games 是唯一游戏目录，Chat 聚合 Honru 对话，Profile 保留现有档案/商城/社交入口。
- 360px 到 1440px 无横向溢出；手机底栏四项可单手触达，桌面不显示手机底栏。
- 昼夜切换时文字、按钮、图标、背景即时适配，个人购买背景不变化。
