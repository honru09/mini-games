# Ghost-native Outcome Surface Design System CLOSE P1

把既有 Victory、Reward Breakdown 与 Achievement Wall 三套互相独立的旧面板，收口为同一套 Ghost-native Outcome Surface：玩家先看清本局结果或成长状态，再看核心数值与明细，最后执行重开、分享、邀请或关闭。

本任务只吸收外部 Q 版 UI 素材的信息层级和反馈节奏；外部角色、图标、字体、PSD/AI/PNG、配色和可识别构图继续保持 `reference-only / blocked-license`，不复制、描摹、换色、导入 Runtime 或上传。

权威边界固定：奖励数值与资格仍全部来自服务端 Reward Breakdown；本任务不修改 Rule、Authority、Protocol、Replay、Supabase、商城价格、经济配置或美术 Manifest。Victory/Reward 可在沉浸式 Game Shell 内播放一次有限结果动效，Achievement 与普通平台弹层在 Game Shell 内静态；所有 Outcome Surface 必须排除旧棋盘/通用弹层 CSS keyframe，避免与 GSAP 同时争夺 transform/opacity。
