# Motion Evidence Schema

首个以及后续每个 GSAP runtime 纵切保存：

- task / route / component / L0–L4 layer；
- 读取的 GSAP skill 与选择的 core/timeline/plugin/utils；
- Motion Token 到 duration/distance/ease 的映射；
- scope、destroy/revert、offscreen、route 与 `ghostgame:shellchange` 生命周期；
- reduced-motion 静态分支；
- bundle before/after、失败 fallback、PWA/CSP/SRI 与回滚；
- 桌面/平板/390px/横屏/低端真机的 FPS、P95 帧耗、long task 和并发动画；
- Authority/规则/Replay/奖励/输入命中区零变化的回归证据。
