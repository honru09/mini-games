# Product Realignment P0｜需求冻结（2026-08-11）

## 目标

把用户最新截图暴露出的“组件已存在但产品仍像网页拼盘”的问题拆成可独立验收的工作流，并在不改变六款游戏规则权威、奖励、Replay、AI 学习、社交安全和数据库边界的前提下逐项收口。

## 本批次 IN

1. **Online-only 与连接韧性**：设置页删除联机服务地址；正式环境固定 Render，同源开发保持可测；认证用户在四区切换、后台/前台、`pageshow`、网络恢复后持续重连；房间 60 秒 resume 与显式退出语义不变。
2. **信息架构**：Home 不再重复个人资料；Profile 独占完整身份、成长和成就；Games 内拆成“选择游戏”和“房间大厅”两个明确工作区；房间创建、浏览、房间码、当前房间、玩家和好友入口归房间工作区。
3. **AI 三档**：删除玩家可见人格选择，只保留简单/普通/困难；三档必须真实改变候选宽度、搜索预算或裁决层级，同时保持合法动作二次校验、个人持续学习和异步过期防护。
4. **Playline 通用动态**：纯文字动态是主入口；游戏、正式结果和记录只是可选附件；保留 All/Friends、删除、举报、Block、访客/Test Admin 隔离和 `textContent` 安全渲染。
5. **六款局内深度**：以真实浏览器几何测量约束 Arena 有效占用；补足回合/思考/落子/掷骰/移动/攻击/消行/结算的可观察进程；用层次、材质、透视、光影和克制动效形成 2.5D/3D 质感，不能靠图标和一段 CSS 冒充完成。
6. **头像与背景**：默认免费目录瘦身并统一 Ghost Game/Honru 主题；新像素头像比现有版本更明显像素化但不退化成低信息块；历史 owned ID 保持兼容。动态背景完成 poster→动效→回退、可见性暂停、reduced-motion 和真实循环验收。
7. **治理**：同步唯一需求台账、六分类/总报告、`PROJECT_STATUS.json`、白皮书/AGENTS（仅事实变化）及新增/修改/删除三份中文日志。

## 明确 OUT / 独立后续

- Playline 图片、视频、评论、点赞、转发和关注：依赖对象存储、内容审核、未成年人/地区合规、举报运营和成本合同，不能混入本 P0。
- 真实 Supabase 迁移、RLS、并发、备份、隔离恢复、多实例、第二浏览器、真机和真实网络整形：继续按外部凭证/设备闸门独立执行。
- 未经用户当前明确命令，不 commit、不 push、不触发 GitHub Pages 或 Render。
- 不改变六款规则、服务端 Authority、奖励数值、Replay 格式、数据库表或 DeepSeek Key/模型环境变量安全边界。

## 截图基线结论

- 五子棋：棋盘位于巨大 Arena 中央，实际占用明显偏小，状态在顶部席位、棋盘角标和右侧命令区重复。
- 飞行棋、大富翁：Wave B 组件存在，但主棋盘缩成中央小卡，属于布局失败而非完成。
- 坦克：主战场尺寸较合理，但地图材质、战斗事件层级和连续反馈不足。
- Tetris：主井可玩，但预览/对手区空间关系松散，命令区和主井缺少统一战斗节奏。
- Games：完整个人摘要、模式、房间、人格、连接、游戏卡、排行和社交纵向堆叠，职责不清。
- Playline：协议支持纯文字，但标题、占位符、侧栏和按钮反复强调游戏分享，形成“只能分享游戏”的错误认知。

## 验收矩阵

| 工作流 | 快速红灯 | 自动化绿灯 | 可见验收 | 回滚 |
| --- | --- | --- | --- | --- |
| 连接/设置 | 设置地址仍可编辑；非房间断线不重连 | Online-only + route/background recovery 专项 | 前后台/切页/断网恢复不掉身份与房间 | 保留服务端默认 URL 常量与既有 resume |
| 信息架构 | Home/Games 重复完整身份；房间与游戏同一长页 | `qa/hub-information-architecture.js` | 桌面/平板/手机两个工作区无重叠 | DOM 分区，不改协议 |
| AI 三档 | 人格仍可见或三档只换文案 | AI difficulty + 六款 AI 强度/合法性 | 三档可理解、默认合理 | 归一化默认 Normal |
| Playline | 首屏继续暗示只能分享游戏 | general-posting + existing UI/protocol QA | 纯文字发布优先，附件次级 | 不扩服务端协议 |
| Game Stage | 静态 CSS 测试通过但 Arena 占用仍小 | 六款密度/过程/销毁专项 | 浏览器量测 + 双主题/横竖屏 | 每款独立 class/flag/fallback |
| 头像/背景 | 免费目录过量且风格漂移 | catalog/provenance/preview lifecycle | 最高质量母图、人工可见审查 | 旧 ID 可读，新目录可回退 |
