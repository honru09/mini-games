# Profile Compare P1 冻结合同

1. 服务器每次响应前必须重新校验正式账号、当前好友和双向 Block。
2. 响应必须同时绑定 `requestId` 与 `targetUid`；客户端换号、取消或迟到响应不得打开旧比较。
3. 比较投影使用固定字段白名单，只含身份、等级、总局数/胜场、六款胜场/称号、成就数量。
4. `profile_get` 及公开 Profile 字段不扩大；不得返回 owned、余额、价格、任务、回放、最近对手、在线偏好或凭据。
5. 好友解除/Block 后请求立即拒绝；访客和陌生人不得读取。
6. 弹层直接使用统一焦点/Esc/背景关闭/滚动锁生命周期，三语言、44px、手机单列。
