# GATE-ART-GOLDEN-SET: User Decision Template

本模板供用户最终决策 Golden Set 的通过情况。请对每一个资产族提供 `APPROVE / REWORK / REJECT` 决议。
> 注意：本表是可选的逐资产风险咨询与方向记录，不是开发或 runtime 的先决条件，也不会自动触发发布。`REJECT` 保留旧版本 Fallback；`APPROVE` 记录额外的所有者偏好，但资产仍须满足 `OWNER_AUTHORIZED_ART_CLEARANCE` 的稳定 ID、SHA、provenance、机器风险审查、fallback 与回滚合同；`REWORK` 表示建议继续迭代。任何线上发布仍需当前用户明确命令。
